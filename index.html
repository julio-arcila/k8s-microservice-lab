Quick Start

# 1. Create k3d cluster
k3d cluster create ai --servers 1 --agents 1

# 2. Deploy everything
kubectl apply -f manifests/

# 3. Access the app
kubectl port-forward -n app svc/frontend-svc 8080:80
curl http://localhost:8080

Real Bugs, Real Lessons

🐛 Issues we debugged live

  • postgres:18-alpine changed volume layout → switched to :16
  • Nginx crash on startup (static DNS) → use resolver + variable
  • Worker nodes can't join (bind-address) → --bind-address=0.0.0.0
  • Manual coredns breaks RBAC → let k3s auto-manage it
  • pip has no internet in k3d → ConfigMap-based deployments
  • PersistentVolumes need provisioner → emptyDir for labs
